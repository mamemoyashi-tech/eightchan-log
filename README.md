# エイトちゃんLOG

黒基調のRX-8向け個人用「愛車維持費・整備履歴」Webアプリ試作版です。

## 主な機能
- 愛車プロフィール
- 愛車写真をホームのメインビジュアルとして登録
- 維持費・整備履歴の記録
- 記録ごとの写真添付
- 今年 / 月平均 / 累計維持費
- 費目別集計
- 最新走行距離
- 検索・編集・削除
- JSONバックアップ / 復元
- CSV出力
- IndexedDBへのローカル保存
- PWA用manifest / service worker

## 使い方
index.html をブラウザで開けば基本機能は利用できます。
PWAとしてホーム画面へ追加する場合は、HTTPSまたはlocalhost上で配置してください。

## 注意
ブラウザのサイトデータを削除するとIndexedDBのデータも削除されます。
定期的に設定画面からJSONバックアップを保存してください。

- 毎月の定例費自動入力（駐車場・保険等）
- 定例費の開始月・終了月・計上日・停止/再開・編集
